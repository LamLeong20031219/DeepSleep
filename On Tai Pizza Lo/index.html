🍕 On Tai Pizza Lo (安泰披薩佬) 項目前期規劃書

本規劃書基於對尊寶披薩商業模式的深度調研分析整理而成

📌 一、尊寶披薩商業模式概覽

尊寶比薩的核心商業模式可以概括為：以「極致性價比」為武器，通過「輕量化小店+中央供應鏈」驅動，在「直營+加盟」雙軌制下快速下沉市場。

簡單來說，就是用極致效率跑通「萬店」邏輯。

1.1 商業模式：性價比驅動的「效率革命」

尊寶的定位非常清晰：避開與必勝客、達美樂在一線商圈的正面競爭，做大眾「家門口的比薩」。

  • 極致性價比：客單價穩定在 30-40元 區間，遠低於必勝客（70-100元）和達美樂（50-80元）
  • 高頻剛需場景：聚焦社區、學校和寫字樓周邊，強調 外帶和外賣（目前外賣佔比已超51%），而非堂食體驗

1.2 核心戰略：「輕量化」與「供應鏈驅動」

戰略支點具體內容
門店輕量化主推30-80㎡的社區小店，標配2-3人即可運營
供應鏈護城河杭州、深圳建有超3萬㎡的中央廚房，48小時冷鏈直達
雙軌制擴張直營店做標杆（廣東超1000家），加盟店攻佔全國市場

1.3 擴張與選址要求

  • 選址邏輯：核心是 高復購、低租金。首選大型社區出入口、學校周邊、寫字樓底商
  • 保護政策：總部給予加盟商 半徑1公里 的區域保護

🔗 四、加盟利潤分配機制

4.1 核心模式

總部賺供應鏈和流水抽成，加盟商拿剩餘利潤。所有營收先進總部賬，扣除固定抽成後再返還給你。

4.2 三項主要費用

4.2.1 營業額抽成（合夥人管理費）

  • 管理費：固定抽取營業額的 2%
  • 階梯式合夥金：
    • 4萬以下：不抽
    • 4萬-12萬：按比例
    • 超過12萬：抽 4%

舉例：月營業額20萬，抽成 = 20萬×2% + (20萬-12萬)×4% = 4000 + 3200 = 7200元

4.2.2 供應鏈利潤

加盟商 必須從總部採購核心原料（麵團、芝士、榴槤肉等），總部會預留利潤空間（約30%-35%）。

4.2.3 一次性費用

項目金額
保證金6萬元
設備+裝修8-12萬元
培訓費約1萬元

4.3 利潤計算公式

你的利潤 = 總營收 - 總部抽成 - 原料採購 - 房租人工等

4.4 月營業額18萬的利潤測算

≈ 月淨利約65,400元此為你最終所得

👨‍🍳 五、員工操作流程

5.1 核心原則

「通崗制」和「傻瓜式」操作。員工不需要精通廚藝，總部把一切都簡化了。

5.2 每日工作流程

開店準備（約1小時）

換上工服 → 清潔消毒 → 檢查冰箱溫度 → 解凍麵團 → 備菜切料

產品製作（核心技能）

  1. 麵團按壓成餅底
  2. 抹上統一配送的醬料
  3. 撒上芝士和餡料
  4. 放入鏈式烤箱（按下按鈕即可）

收銀與服務

接聽電話或收銀，按標準話術推薦「最划算」的套餐。

5.3 披薩製作四步法

步驟操作關鍵要點
1. 鋪將麵團按壓成標準尺寸餅底力道均勻，厚薄一致
2. 撒抹醬→撒芝士→放餡料→再撒芝士必須按標準克重，禁止憑手感
3. 烤放入鏈式烤箱傳送帶速度固定，約6-6.5分鐘
4. 切出爐後用滾輪刀分切通常切8等份，打包出餐

5.4 烘烤時間

  • 標準時間：6分鐘到6分30秒
  • 烤箱溫度：215°C
  • 設備類型：鏈式烤箱（傳送帶自動輸送）

5.5 班次安排

班次時間特點
A班9點30分-13點30分 和 17點00分-22點30分兩頭班，兼顧堂食外賣高峰
B班10點20分-20點00分直落班

5.6 人員架構

  • 店員（通崗）：輪流負責製作、收銀、外送
  • 副店長：協助排班、處理客訴、盤點物料
  • 店長：管全店賬目、成本控制、考核員工

5.7 晉升路徑

店員/學徒 → 副店長（1-3個月） → 店長 → 督導（管6-8家店）

公司內部流傳「33%的店長晉升比率」，每月一次晉升考核。

5.8 新員工培訓（7天帶薪）

時間內容
第1天入職入住，了解公司，免費品嚐各種披薩
第2-6天門店實操，老員工帶教
第7天考核鑑定，必須能不看手冊獨立完成製作

📌 香港本地化營運策略 · 安泰披薩佬實戰藍圖

💡 以下內容根據香港獨特嘅市場環境、公屋文化、外賣生態及成本結構作出全面分析，說明「尊寶模式」移植到香港安泰邨嘅可行性、調整策略以及盈利預估。
✅ 呢個項目「有得做」，但要「做得精」

🔍 1. 市場有需求 —— 香港人鍾意平價外賣披薩

香港人對「平價+快+外賣」嘅披薩需求強烈，尤其係公屋區、學生區、打工仔集中地。現時市場有 達美樂（Domino’s）、必勝客（Pizza Hut）、本地小品牌（如 Pizza Express、Pizza King），但缺乏「極致性價比」嘅社區小店。選「安泰邨」做起點，位置極佳 —— 公屋區、人口密集、年輕家庭多、外賣需求高，正正係尊寶模式嘅理想市場。

📊 2. 尊寶模式在香港有「複製空間」

尊寶優勢香港適用性
輕量化小店（30-80㎡）香港租金貴，但安泰邨周邊有底商、街鋪、甚至「工廈改裝」，可控制成本
中央廚房 + 冷鏈配送香港物流成熟，可與本地供應商合作（如新鮮麵團、芝士、榴槤肉），唔使完全跟尊寶
外賣為主（>50%）香港外賣平台（Foodpanda、Deliveroo、Uber Eats）發達，可直接接入
爆品策略（榴槤披薩）香港人鍾意榴槤，「榴槤披薩」係天然爆品，可打「港式榴槤」概念

💰 3. 成本與盈利 —— 香港要「再精算」

✅ 建議：控制人力：用「通崗制」，1人做3事（製作、收銀、外送）；自採部分原料：如青椒、粟米、菠蘿，本地市場買，降低成本；主打「外賣+自取」：減少堂食空間，節省租金。

📍 4. 安泰邨 —— 理想起點，但要「避開競爭」

✅ 優勢：人口密集（安泰邨 + 安達邨 + 秀茂坪，總人口超 5 萬）；年輕家庭多，外賣需求高，尤其週末、晚上；交通便利，有巴士、港鐵（藍田站），方便外送；租金相對低，相比九龍塘、尖沙咀，安泰邨底商租金較親民。
⚠️ 風險：競爭者（附近可能有 Pizza King、Pizza Express，甚至達美樂外送）；密度內耗；品控難（香港人對食安要求高）。
✅ 建議：先開「試驗店」（50㎡以下小店），主打「港式口味」如燒鵝披薩、叉燒披薩、咖喱雞披薩，用「會員制」（買10個送1個）提高復購率。

📈 5. 盈利模型 —— 香港版「尊寶」要「再優化」

🛠 6. 操作流程 —— 香港要「更簡化」

✅ 香港版「通崗制」建議：1人負責「製作+收銀」（用平板點單自動打印），1人負責「外送+補貨」（用電單車），店長每週來2次檢查品控。
⚠️ 香港人對「速度」要求高：披薩出餐時間必須10分鐘內，外送時間30分鐘內，超時要賠償（可設「超時免單」）。

📦 7. 原料採購 —— 香港要「本地化」

✅ 可自採：青椒、粟米、菠蘿、蘑菇 → 本地市場買，新鮮又平；飲品與維他奶、可口可樂合作拿批發價。
❗ 必須用「高品質」：芝士用「安佳」或「百吉福」，榴槤用「蘇丹王」或「貓山王」，麵團可與本地麵包廠合作每日新鮮配送。

📌 8. 風險管理 —— 香港要「更謹慎」

風險應對方案
食安投訴每日檢查冰箱溫度、食材新鮮度，拍片存證
平台抽成高推「自取優惠」，減少對平台依賴
競爭圍剿打「港式口味」、「邨內專享」，建立忠誠度
人力成本高用「兼職學生」、「退休人士」，靈活排班

🎯 9. 總結：安泰披薩佬 —— 有得做，但要「香港化」

✅ 成功關鍵：選對位置（安泰邨周邊）、控制成本（通崗制+自採原料）、打出特色（港式披薩/榴槤爆品/邨內專享）、做好品控（快速回應投訴）。
❌ 失敗陷阱：照搬尊寶、貪大求全、忽視外賣平台接入。
💡 最後建議：先開「試驗店」，再擴張
第一步：租30㎡小店，測試「榴槤披薩」、「港式口味」市場反應。
第二步：用「會員制」、「邨內專享」提高復購率。
第三步：如果月利潤 > HK$10,000，再開第二間，甚至做「安泰邨連鎖」。

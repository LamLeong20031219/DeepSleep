## 📌 一、尊宝披萨商业模式概览

尊宝比萨的核心商业模式可以概括为：**以“极致性价比”为武器，通过“轻量化小店+中央供应链”驱动，在“直营+加盟”双轨制下快速下沉市场**。

简单来说，就是用极致效率跑通“万店”逻辑。

### 1.1 商业模式：性价比驱动的“效率革命”

尊宝的定位非常清晰：**避开与必胜客、达美乐在一线商圈的正面竞争，做大众“家门口的比萨”**。

- **极致性价比**：客单价稳定在 **30-40元** 区间，远低于必胜客（70-100元）和达美乐（50-80元）
- **高频刚需场景**：聚焦社区、学校和写字楼周边，强调 **外带和外卖**（目前外卖占比已超51%），而非堂食体验

### 1.2 核心战略：“轻量化”与“供应链驱动”

| 战略支点 | 具体内容 |
| --- | --- |
| 门店轻量化 | 主推30-80㎡的社区小店，标配2-3人即可运营 |
| 供应链护城河 | 杭州、深圳建有超3万㎡的中央厨房，48小时冷链直达 |
| 双轨制扩张 | 直营店做标杆（广东超1000家），加盟店攻占全国市场 |

### 1.3 扩张与选址要求

- **选址逻辑**：核心是 **高复购、低租金**。首选大型社区出入口、学校周边、写字楼底商
- **保护政策**：总部给予加盟商 **半径1公里** 的区域保护

### 1.4 成本与盈利模型

| 指标 | 数据 |
| --- | --- |
| 单店总投资 | 30-50万元 |
| 毛利率 | 约60% |
| 净利润率 | 15%-25% |
| 回本周期 | 12-18个月（理想情况） |

## 🔗 四、加盟利润分配机制

### 4.1 核心模式

**总部赚供应链和流水抽成，加盟商拿剩余利润**。所有营收先进总部账，扣除固定抽成后再返还给你。

### 4.2 三项主要费用

#### 4.2.1 营业额抽成（合伙人管理费）

- **管理费**：固定抽取营业额的 **2%**
- **阶梯式合伙金**：
    - 4万以下：不抽
    - 4万-12万：按比例
    - 超过12万：抽 **4%**

> **举例**：月营业额20万，抽成 = 20万×2% + (20万-12万)×4% = 4000 + 3200 = 7200元

#### 4.2.2 供应链利润

加盟商 **必须从总部采购核心原料**（面团、芝士、榴莲肉等），总部会预留利润空间（约30%-35%）。

#### 4.2.3 一次性费用

| 项目 | 金额 |
| --- | --- |
| 保证金 | 6万元 |
| 设备+装修 | 8-12万元 |
| 培训费 | 约1万元 |

### 4.3 利润计算公式

**你的利润 = 总营收 - 总部抽成 - 原料采购 - 房租人工等**

### 4.4 月营业额18万的利润测算

| 项目 | 金额 | 说明 |
| --- | --- | --- |
| 月营业额 | 180,000元 | 日均150单×40元 |
| 减：总部抽成 | 约6,600元 | 管理费3600 + 阶梯抽成3000 |
| 减：原料成本 | 约63,000元 | 按毛利率65%倒推 |
| 减：房租人工 | 约45,000元 | 房租2万 + 人工2.5万 |
| ≈ 月净利 | 约65,400元 | 此为你最终所得 |

## 👨‍🍳 五、员工操作流程

### 5.1 核心原则

**“通岗制”和“傻瓜式”操作**。员工不需要精通厨艺，总部把一切都简化了。

### 5.2 每日工作流程

#### 开店准备（约1小时）

换上工服 → 清洁消毒 → 检查冰箱温度 → 解冻面团 → 备菜切料

#### 产品制作（核心技能）

1. 面团按压成饼底
2. 抹上统一配送的酱料
3. 撒上芝士和馅料
4. 放入链式烤箱（按下按钮即可）

#### 收银与服务

接听电话或收银，按标准话术推荐“最划算”的套餐。

### 5.3 披萨制作四步法

| 步骤 | 操作 | 关键要点 |
| --- | --- | --- |
| 1. 铺 | 将面团按压成标准尺寸饼底 | 力道均匀，厚薄一致 |
| 2. 撒 | 抹酱→撒芝士→放馅料→再撒芝士 | 必须按标准克重，禁止凭手感 |
| 3. 烤 | 放入链式烤箱 | 传送带速度固定，约6-6.5分钟 |
| 4. 切 | 出炉后用滚轮刀分切 | 通常切8等份，打包出餐 |

### 5.4 烘烤时间

- **标准时间**：**6分钟到6分30秒**
- **烤箱温度**：**215°C**
- **设备类型**：链式烤箱（传送带自动输送）

### 5.5 班次安排

| 班次 | 时间 | 特点 |
| --- | --- | --- |
| A班 | 9点30分-13点30分 和 17点00分-22点30分 | 两头班，兼顾堂食外卖高峰 |
| B班 | 10点20分-20点00分 | 直落班 |

### 5.6 人员架构

- **店员（通岗）**：轮流负责制作、收银、外送
- **副店长**：协助排班、处理客诉、盘点物料
- **店长**：管全店账目、成本控制、考核员工

### 5.7 晋升路径

店员/学徒 → 副店长（1-3个月） → 店长 → 督导（管6-8家店）

> 公司内部流传“33%的店长晋升比率”，每月一次晋升考核。

### 5.8 新员工培训（7天带薪）

| 时间 | 内容 |
| --- | --- |
| 第1天 | 入职入住，了解公司，免费品尝各种披萨 |
| 第2-6天 | 门店实操，老员工带教 |
| 第7天 | 考核鉴定，必须能不看手册独立完成制作 |

## ⚠️ 八、潜在风险与挑战

| 风险类型 | 具体表现 |
| --- | --- |
| 盈利压力 | 单店营收效率远低于达美乐，回本周期可能拉长至2年以上 |
| 管理难度 | 3000多家加盟店的品控难题，2025年曾出现“生食交付”投诉 |
| 竞争围剿 | 下方有小品牌价格战，上方有必胜客“卫星店”和达美乐下沉挤压 |
| 密度内耗 | 部分区域1公里内多家店，总部赚双倍抽成，但你的单店营收被稀释 |
| 直营优先 | 好位置总部优先开直营店，加盟店可能面临“被包围”的竞争压力 |

## ✅ 九、给加盟商的建议

1. **选址核实**：确认总部承诺的 **1公里保护范围** 是否写进合同
2. **盈利预期**：做好 **24个月甚至更久** 回本的心理和资金准备
3. **外卖占比**：如果外卖超过7成，平台扣点会直接吃掉利润
4. **盯紧出品**：员工为图快可能少放芝士或馅料，这是客诉增多主因
5. **别在原料上省钱**：私采非标原料可能导致6万保证金被扣
6. **利用晋升机制留人**：每月都有晋升考核，给年轻人希望
